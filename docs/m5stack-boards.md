# M5Stack board and firmware references

These product entries have Wi-Fi, Bluetooth and at least 8 MiB of flash. Hardware revisions and bundled products share a runtime when they use the same host controller. Accessory peripherals still require their own drivers. The table lists on-chip SRAM separately from external PSRAM.

The UIFlow targets use the M5Stack board port. The generic targets use the ESP32 port in the pinned MicroPython submodule with the ESPHub SDK. See the [runtime build configuration](../firmware/pyrt/upstream.json) and [simulator instructions](../tools/micropython-sim/README.md).
